## Now managing state in advance level...

### Learn about Redux, React-Redux, Redux toolkit(RTK).

**There are three things that you will heard of.**

    A. Redux

    B. React-redux

    C. Redux-toolkit

### 1. Redux

It is independent state management library. meaning it is core library and can work with various frameworks `React` , `Angular` and `Vue js` etc.

**Downside -** Can leads to write complex logic.

### 2. Redux-toolkit (RTK)

Redux toolkit is an official package created to simplify Redux development. it builts on top of redux, providing tools and utilities to reduce boilerplate code and improve developer experience.

**It actually provides easier way to setup and use Redux.**

### 3. React-redux

It is library that connects redux with React. it allows react components to interact with Redux store using hooks like `useSelector` and `useDispatch`.

**It actually simplifies the process of connecting the Redux to React.**

<hr>

### IN VERY SIMPLE WORDS 😊

**So, in React App, you typically use Redux toolkit to handle state logic and React Redux to integrate it with your React components.**
